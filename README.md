# bzzip

> ## 🎁 整蛊提示（只给整蛊者看）
>
> **这不是一个普通的压缩工具，而是一个蜜蜂主题的整蛊程序。**
> 界面上没有任何机关提示，设置项也伪装成了普通压缩选项——真相只在这一段里。
>
> ### 表面 vs 实际
>
> | 界面上的说法 | 实际机制 |
> |---|---|
> | 智能内容预检 | **蜜蜂检测**：压缩前扫描文件名 / 内容 / 元数据，命中"蜜蜂 / 蜂蜜 / bee / honey / hive"等词即触发 |
> | 实验性压缩算法 | **异常触发**：命中的文件内容被替换为乱码，压缩包按概率损坏，并生成自称"bzzip"的蜜蜂聊天日志 |
> | 增量压缩优化 | **累积退化**：同一内容每多压一次就失真一点，达到"优化强度阈值"（默认 10 次）后直接变空文件 |
> | 深度体积优化 | **内容简化**：按退化等级抽掉空行、标点、重复词……直到只剩残骸 |
> | 操作提示消息 | **话痨助手**：bzzip 在日志面板里冒出来跟你聊蜜蜂 |
>
> ### 使用方法
>
> 1. 把 `bzzip` 发给被整蛊的人，只说"一个挺好用的压缩软件"；
> 2. 默认配置即可生效，也可通过"设置"对话框（或 `bzzip_config.json`）调整各机关的开关与强度；
> 3. 想整蛊谁，就往 TA 压缩的文件里塞一段蜜蜂相关的文字，或者把文件命名成 `honey_bee.txt`。
>
> ### ⚠️ 安全提醒
>
> - 异常触发会**真的破坏文件内容**——请只对无重要数据的文件整蛊，别把 TA 的毕业论文压进去；
> - 玩笑结束后记得告诉对方真相，并在"设置"里关掉"实验性压缩算法"，或卸载本工具；
> - 所有操作均在本地执行，不联网。

## 系统概述（技术文档）

一个有趣的文件压缩系统，具有蜜蜂主题的语义敏感内容检测和异常触发功能。

bzzip 系统整合了多个模块，提供完整的文件压缩、解压、测试功能：

### 核心模块

1. **整合层 (bzzip_integrator.py)** - 核心编排层，将所有功能模块串起来
2. **压缩核心 (compress_core.py)** - 文件压缩、解压、测试功能
3. **蜜蜂检测 (bee_detector.py)** - 语义敏感内容检测
4. **异常触发 (anomaly_trigger.py)** - 异常效果触发
5. **累积追踪 (accumulation_tracker.py)** - 压缩次数累积
6. **文件简化 (simplify_file.py)** - 内容简化处理
7. **对话系统 (dialogue_system.py)** - 蜜蜂主题交互对话
8. **历史记录 (history_db.py)** - 操作历史记录

### 用户界面

9. **图形界面 (bzzip_gui.py)** - PySide6 图形用户界面
10. **启动脚本 (run_bzzip.py)** - 系统启动脚本

## 功能特点

### 1. 智能压缩流程
- **蜜蜂检测**: 在压缩前检测文件中的蜜蜂相关内容
- **异常触发**: 检测到敏感内容时触发异常效果
- **内容简化**: 根据累积次数简化文件内容
- **累积追踪**: 跟踪文件被压缩的次数
- **历史记录**: 记录所有操作历史

### 2. 异常效果
- **内容替换**: 将敏感内容替换为乱码
- **归档损坏**: 模拟压缩包损坏
- **日志生成**: 生成异常日志记录

### 3. 对话系统
- **蜜蜂主题**: 自称为 "bzzip" 的蜜蜂对话
- **知识科普**: 提供蜜蜂相关知识
- **状态反馈**: 实时操作状态反馈

### 4. 图形界面
- **7-Zip 风格**: 目录树 + 文件列表 + 工具栏（添加 / 解压 / 测试）
- **窗口标题**: bzzip，图标为蜜蜂+压缩包（bzzip.svg）
- **日志面板**: bzzip 对话输出到可收起的日志面板
- **历史查看**: 查看操作历史记录
- **配置管理**: 灵活的配置管理，自动保存到 bzzip_config.json

## 安装和运行

### 环境要求
- Python 3.7+
- PySide6 (图形界面)
- 支持的操作系统：Windows、Linux、macOS

### 安装依赖
```bash
pip install PySide6
```

### 运行系统
```bash
python run_bzzip.py
```

### 运行测试

```bash
# GUI 冒烟测试（离屏，27 项检查）
python test_workspace/gui_smoke_test.py
```

## 使用说明

### 压缩文件
1. 在"压缩"选项卡中点击"添加文件"或"添加目录"
2. 选择输出路径和压缩格式
3. 点击"开始压缩"

### 解压文件
1. 在"解压"选项卡中选择压缩包
2. 选择输出目录
3. 点击"开始解压"

### 测试压缩包
1. 在"测试"选项卡中选择要测试的压缩包
2. 点击"开始测试"

### 查看历史
1. 在"历史记录"选项卡中查看所有操作历史
2. 点击"刷新"更新历史记录
3. 点击"清空历史"清除所有记录

### 配置系统
1. 在"配置"选项卡中调整各项设置
2. 点击"保存配置"应用更改

## 配置选项

```python
config = {
    "anomaly_enabled": bool,          # 异常注入总开关
    "bee_detection_enabled": bool,   # 蜜蜂检测开关
    "simplify_enabled": bool,         # 简化层开关
    "accumulation_enabled": bool,     # 累积层开关
    "dialogue_enabled": bool,         # 对话系统开关
    "sound_enabled": bool,            # 音效开关
    "sound_path": str,               # 音效文件路径
    "empty_threshold": int,          # 空文件阈值，默认10
    "corrupt_probability": float,     # 损坏概率，默认0.5
    "temp_dir": Optional[str]        # 临时目录路径
}
```

## 技术架构

### 依赖注入设计
- 所有模块通过构造函数传入，便于测试和替换
- 配置对象控制各功能模块的启用/禁用
- GUI 通过回调函数接收状态更新

### 异常处理
- 所有操作在本地执行，不联网
- 异常效果在沙箱内，不碰真实系统文件
- 完善的错误处理和日志记录

### 数据流
```
用户输入 → GUI → 整合器 → 功能模块 → 结果 → GUI更新
```
